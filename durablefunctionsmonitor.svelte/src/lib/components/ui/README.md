# Restyled shadcn-svelte primitives

Generated by `npx shadcn-svelte@1.6.1 add …` (E1-S1-T2) and then rewritten so that every element carries
a class from `src/styles/dfm-ui.css` instead of Tailwind utilities. They exist for the behaviour that is
tedious and easy to get wrong - focus traps, roving focus, typeahead, portals, escape and outside-click,
ARIA wiring - and for nothing else.

**These files are the only place `bits-ui` is imported directly.** Everything else in the app imports
from here, or from the DFM components in `src/lib/components/` that wrap them.

## What maps to what

| Primitive                  | Element                                      | DFM class (dfm-ui.css)                                           |
| -------------------------- | -------------------------------------------- | ---------------------------------------------------------------- |
| `dialog`, `alert-dialog`   | overlay                                      | `overlay`                                                        |
|                            | content                                      | `dialog`                                                         |
|                            | header                                       | `body`                                                           |
|                            | title                                        | `display`                                                        |
|                            | footer                                       | `foot`                                                           |
|                            | alert action / cancel                        | `btn primary` / `btn`                                            |
| `dropdown-menu`, `popover` | content                                      | `pop` (add `right` when `align="end"`)                           |
|                            | item, checkbox item, radio item, sub trigger | `mi` (`mi destructive` for a destructive action)                 |
|                            | separator                                    | `sep`                                                            |
|                            | label, group heading                         | `grp`                                                            |
|                            | shortcut                                     | `kbd`                                                            |
| `select`                   | trigger                                      | `input`, inside a `<div class="sel">` the caller renders         |
|                            | content                                      | `pop`                                                            |
|                            | item                                         | `mi` (the chosen one wraps its label in `.active`)               |
| `command`                  | root                                         | `palette`                                                        |
|                            | input                                        | none - `.palette > input` is styled by the child selector        |
|                            | list                                         | `plist`                                                          |
|                            | group heading                                | `grp`                                                            |
|                            | item                                         | `prow` (the active row is `prow sel`)                            |
|                            | shortcut                                     | `kbd`                                                            |
|                            | dialog                                       | `overlay pal` + `palette`                                        |
| `checkbox`                 | root                                         | `box` (+ `on` when checked)                                      |
| `switch`                   | root                                         | `switch` (+ `on` when checked)                                   |
| `tabs`                     | list                                         | `tabs`                                                           |
|                            | trigger                                      | `tab` (selected state is `aria-selected`, which the CSS keys on) |
| `tooltip`                  | content                                      | `pop meta`                                                       |
| `sheet`                    | content `side="right"`                       | `peek`                                                           |
|                            | content `side="bottom"`                      | `sheet`                                                          |
| `table`                    | container / table                            | `tbl-wrap` / `tbl`                                               |

## Rules

- The stylesheet draws with pseudo-elements what shadcn draws with extra elements, so several indicator
  nodes are gone: `.box.on::after` is the check mark, `.switch::after` the knob, `.sel::after` the select
  arrow, `.mi.active` and `.prow.sel` the chosen row. Do not add icons back.
- Dialogs have no floating close button; every dialog in the mockups closes through its own `.foot`.
- `cn()` survives only as class passthrough (`cn('pop', className)`); `tailwind-variants` is gone.
- Keep the `data-slot` attributes: they are how the component tests and any future debugging find an
  element, and they cost nothing.
- Regenerating a primitive with the CLI overwrites these files. If that happens, redo the mapping above
  and re-run `tests/unit/ui-primitives.test.ts`, which fails on any Tailwind utility class that comes back.
